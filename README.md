A program that writes one line: the apology a smart speaker gives its owner after mishearing them. Three hand-written candidate lines are scored against the judge's criteria — on-brief apology, funny twist, freshness, device voice, tightness — and the strongest wins deterministically. No randomness, no network, no files read.

## Run it

```sh
python3 main.py
```

The winning line is written to `/output/entry.txt` (or `$ENTRY_OUTPUT` if set).
